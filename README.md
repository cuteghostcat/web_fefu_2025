Развёртывание на Ubuntu:
1. Скачайте проект - wget https://github.com/cuteghostcat/web_fefu_2025
2. Перейдите в папку проекта - cd web_fefu_2025
3. Добавьте право использования на скрипт - chmod +x django/entrypoint.sh
4. Запустите докер(находясь в корне проекта) - docker-compose up -d
5. Ждите. Если всё прошло успешно, то сервис запуститься
